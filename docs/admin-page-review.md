## 2026-04-24 확인 결과
- `768px` 이하에서 사이드바가 화면 밖으로 숨겨지지만 열기 버튼이나 토글 상태 연결이 없어 모바일에서 메뉴 접근이 막힌다.
- 차트는 `400px~500px` 고정 폭 SVG를 사용해 작은 화면에서 카드 폭보다 넓어질 수 있다.
- 카테고리 판매량 차트는 임시 랜덤 값을 사용해 실제 운영 지표처럼 보이지만 신뢰할 수 없는 데이터를 보여준다.
- 인증 확인 화면은 인라인 스타일과 보라색 그라데이션을 사용해 관리자 대시보드 본문 톤과 시각적으로 분리된다.
- 공통 네비게이션은 현재 위치를 드러내는 active 상태가 없어 메뉴 밀도가 높은 화면에서 현재 섹션 인지가 약하다.

## 2026-04-24 후속 정리 메모
- `src/app/admin/layout.module.css`의 배경, 보더, 텍스트, 버튼, 스크롤바는 전역 토큰(`--off-white`, `--line`, `--text-subtle`, `--black`, `--radius-md`)으로 다시 맞췄다.
- 그래서 관리자 화면의 기본 톤은 메인 쇼핑몰과 같은 시스템 안으로 들어왔지만, 모바일 메뉴 진입 불가와 active 상태 부재 같은 구조 문제는 그대로 남아 있다.

## 2026-05-12 관리자 전체 톤 정리
- `src/app/admin/layout.module.css`에 관리자 하위 페이지 전반을 감싸는 운영툴형 보정 레이어를 추가했다.
- 관리자 하위 카드, 섹션, 테이블, 모달, 버튼, 입력, 배지, active nav는 2px radius, 얇은 보더, 검정 CTA, 중립 배경으로 낮췄다.
- 보라/파랑 그라데이션이 강한 `dashboard/dashboard`, `seed`, 상품 수정 모달, 이벤트 폼, 공통 Add/Edit 모달, 로딩/에러 컴포넌트는 파일별 override를 추가했다.
- 권한 가드, 데이터 조회, 저장 로직은 변경하지 않았다.

## 후속 제안
- 모바일 헤더에 메뉴 버튼과 오버레이 닫기 흐름을 추가하고, 현재 경로 active 스타일을 네비게이션에 연결한다.
- 차트는 컨테이너 기준으로 너비를 계산하거나 반응형 SVG로 바꾸고, 실제 집계 데이터만 노출한다.
- 인증 로딩/권한 오류 상태도 관리자 공통 토큰과 컴포넌트로 맞춰 첫 진입 경험을 일관되게 만든다.

## 2026-05-12 기능 피드백 반영
- `/admin` 카테고리 차트의 임시 랜덤 값을 제거하고 `DashboardService.categoryBreakdown` 실제 집계값을 표시하도록 변경했다.
- 관리자 공통 내비게이션에 현재 경로 active 상태와 모바일 메뉴 열기/닫기 흐름을 연결했다.
- 주문 상태 변경은 `/api/order`의 관리자 전용 `updateStatus` 액션으로 서버화하고 상태 전이 검증 및 변경 이력을 남기도록 했다.
- 쿠폰 마스터 생성/수정/비활성화는 `/api/coupon` 관리자 액션으로 이동했고, 삭제 버튼은 발급 이력 보존을 위해 비활성화 처리로 바꿨다.

## 2026-07-27 관리자·지원 디자인 문법 정리
- 관리자 대시보드·이벤트·문의·쿠폰과 공개 Q&A의 장식용 3px 측면·상단 강조선을 얇은 공용 테두리로 통일했다. 오류, 답변, 재고 같은 상태는 기존의 텍스트 라벨과 semantic 색상을 유지해 색상만으로 의미를 전달하지 않는다.
- 로딩 스피너의 원형 회전 테두리는 기능 요소로 보존하고, 품질 검사에서도 일반 장식 accent와 구분한다.
- 오프라인 매장 카드 이미지의 하단 장식 stripe만 제거했으며 주소·운영시간·문의 정보의 구조와 기존 권한·폼·목록 동작은 변경하지 않았다.
