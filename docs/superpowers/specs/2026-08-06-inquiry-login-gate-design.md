# 1:1 문의 비로그인 안내 설계

## 목표

- 비로그인 방문자가 1:1 문의 이용 조건과 다음 행동을 즉시 이해하게 한다.
- 로그인 완료 후 `/cs/inquiry/`로 복귀해 바로 문의를 작성할 수 있게 한다.
- 기존 문의 화면의 절제된 흑백·보더 중심 톤을 유지하고, 모바일에서도 버튼과 안내문이 안정적으로 읽히게 한다.

## 범위

### 포함

- `/cs/inquiry/`의 비로그인 전용 안내 상태
- 로그인 화면으로의 안전한 복귀 경로 전달
- 인증 확인 중 로딩 상태
- 데스크톱·태블릿·모바일 레이아웃 및 접근성 기준

### 제외

- 로그인·회원가입 화면의 시각 개편
- 문의 작성·문의 내역 탭의 로그인 사용자 UI 변경
- 별도 도움말, 챗봇, 아이콘 또는 일러스트 추가

## 화면 구성

- 비로그인 상태에서는 문의 탭과 폼을 렌더링하지 않고, 기존 문의 콘텐츠 폭 안에 전용 안내 패널만 표시한다.
- 패널은 작은 상단 레이블, 제목, 설명, 주 버튼, 복귀 안내 순서로 구성한다.
- 문구는 다음을 사용한다.
  - 레이블: `1:1 INQUIRY`
  - 제목: `로그인 후 1:1 문의를 남길 수 있어요`
  - 설명: `문의 작성과 답변 확인은 로그인한 회원만 이용할 수 있습니다.`
  - 주 버튼: `로그인하고 문의하기`
  - 보조 안내: `로그인 후 현재 페이지로 돌아와 문의를 바로 작성할 수 있습니다.`

## 동작과 상태

- 주 버튼은 링크로 구현하고 `/auth/login?redirect=/cs/inquiry`로 이동한다.
- 로그인 성공 후 인증 화면은 `redirect` 값을 검증한 뒤 `/cs/inquiry/`로 이동한다.
- 인증 상태를 아직 확인하는 동안에는 비로그인 안내를 먼저 표시하지 않는다. `로그인 상태를 확인하고 있습니다.`라는 짧은 상태 메시지만 보여 로그인 안내가 순간적으로 노출되는 현상을 막는다.
- 로그인한 사용자는 기존의 문의 작성·문의 내역 탭과 데이터 조회 흐름을 그대로 사용한다.

## 레이아웃과 반응형

- 데스크톱(769px 이상): 기존 문의 영역 내에서 최대 520px 폭 패널을 가운데 배치한다. 안내 상태가 페이지 중앙에 안정적으로 위치하도록 충분한 세로 여백을 확보한다.
- 태블릿(481~768px): 패널의 최대 폭은 유지하고, 컨테이너 좌우 여백만 축소한다.
- 모바일(480px 이하): 패널은 사용 가능한 전체 폭을 쓰고, 주 버튼은 전체 폭으로 확장한다. 텍스트 줄바꿈을 고려해 내부 여백을 줄이되 정보 위계는 유지한다.
- 모든 화면에서 주 버튼은 최소 44px 높이를 유지한다.

## 시각·접근성 기준

- 기존 문의·마이페이지 접근 제한 UI의 검정 버튼, 얇은 보더, 흰색 또는 옅은 회색 면을 재사용한다.
- 그림자, 신규 아이콘, 장식성 일러스트, 과도한 둥근 모서리는 추가하지 않는다.
- 고객센터 공통 레이아웃의 `도움말` h1을 유지하고, 안내 패널 제목은 h2로 제공한다. CTA는 실제 링크로 제공한다.
- 키보드 포커스가 충분히 보이고, 링크의 이름만으로 로그인 후 문의 작성 목적을 이해할 수 있어야 한다.

## 검증 기준

- 비로그인 상태에서 안내 문구와 로그인 링크가 렌더링되고, 링크가 `/auth/login?redirect=/cs/inquiry`를 가리킨다.
- 인증 확인 중에는 비로그인 안내 대신 로딩 상태만 보인다.
- 로그인 상태에서는 기존 문의 탭·폼·문의 내역 동작이 유지된다.
- 데스크톱과 480px 이하 모바일 폭에서 텍스트 넘침 없이 CTA가 44px 이상으로 표시된다.
