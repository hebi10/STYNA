# STYNA FILM 무음 자동 재생 섹션 설계

## 목표

- 홈에서 네 개의 AI 상품 영상을 하나의 40초 브랜드 필름으로 보여 준다.
- 상품 탐색보다 무드 경험을 우선하되, 하단의 작은 상품 이미지와 텍스트로 각 영상의 상품을 인지·이동할 수 있게 한다.
- 영상을 무한 반복하지 않아 메인 페이지의 집중도와 리소스 사용량을 통제한다.

## 배치와 구성

- 홈의 `STYNA SELECT` 다음, 신상품 이전에 `STYNA FILM` 섹션을 추가한다.
- 상단에는 `STYNA FILM` 라벨, `THE EVERYDAY MOTION` 제목과 짧은 보조 문구를 둔다.
- 중앙에는 현재 챕터 영상 하나만 크게 보인다. 하단에는 번호, 작은 이미지, 브랜드, 상품명만 포함한 4개 상품 스트립을 둔다.
- 상품 스트립은 영상 순서를 바꾸지 않는 상세 링크다. 데스크톱은 4열, 모바일은 가로 스크롤을 사용한다.

## 영상 순서와 재생 계약

1. 쿨터치 오버핏 반팔 셔츠 — 0:00~0:10
2. 메쉬 로우프로파일 스니커즈 — 0:10~0:20
3. 유틸리티 빅 토트백 — 0:20~0:30
4. 라이트 집업 재킷 — 0:30~0:40

- 섹션이 화면에 다시 진입하면 언제나 1번 영상을 0초부터 무음 자동 재생한다.
- 활성 영상이 끝나면 다음 영상으로 자동 전환한다. 4번 영상이 끝나면 첫 영상으로 돌아가지 않고 정지한다.
- 섹션이 기준 노출 영역을 벗어나면 현재 재생을 중지하고, 다음 진입을 위해 모든 챕터를 처음 상태로 되돌린다.
- 영상에는 `muted`, `playsInline`, `autoPlay`를 사용하며 사용자에게 음소거 해제·볼륨·재생 순서 변경 컨트롤을 제공하지 않는다.
- 운영체제의 `prefers-reduced-motion`이 활성화된 방문자에게는 자동 재생 대신 대표 이미지만 제공한다. 이는 모션 감소 설정을 존중하는 예외다.

## 자산과 성능

- 제공 영상은 `public/videos/styna-film/`에 식별 가능한 영문 파일명으로 배치한다. 원본 다운로드 파일명은 공개 URL로 사용하지 않는다.
- 화면에는 활성 영상만 재생하고, 다음 영상은 메타데이터 또는 포스터 수준으로만 준비한다.
- 각 영상에는 대응하는 기존 메인 배너 이미지를 포스터로 둔다. 로드 실패 시 포스터와 상품 스트립은 유지하며, 자동 다음 전환만 건너뛴다.
- 비활성 영상은 일시 정지·초기화해 백그라운드 네트워크와 디코딩을 제한한다.

## 접근성과 검증

- 섹션·현재 영상·상품 스트립에 의미 있는 레이블을 제공하고, 영상 장면의 핵심은 텍스트 제목과 상품명으로도 전달한다.
- 4개 영상의 순서, 재진입 초기화, 4편 종료 뒤 정지, 무음 고정, 모션 감소 예외, 모바일 스트립 가로 스크롤을 테스트한다.
- 영상 파일의 실제 재생 시간·코덱·해상도는 구현 전에 확인하고, 각 영상이 10초가 아니라면 완료 이벤트를 기준으로 다음 챕터를 전환한다.
