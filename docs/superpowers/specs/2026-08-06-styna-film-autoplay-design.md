# STYNA FILM 무음 자동 재생 섹션 설계

## 목표

- 홈에서 네 개의 AI 상품 영상을 하나의 40초 브랜드 필름으로 보여 준다.
- 상품 탐색보다 무드 경험을 우선하되, 하단의 작은 상품 이미지와 텍스트로 각 영상의 상품을 인지·이동할 수 있게 한다.
- 영상을 무한 반복하지 않아 메인 페이지의 집중도와 리소스 사용량을 통제한다.

## 배치와 구성

- 홈의 `STYNA SELECT` 다음, 신상품 이전에 `STYNA FILM` 섹션을 둔다.
- 중앙에는 현재 챕터 영상 하나를 크게 보여 주고, 하단에는 번호·작은 이미지·브랜드·상품명으로 이뤄진 4개 상품 링크 스트립을 둔다.
- 상품 링크는 영상 순서를 바꾸지 않으며, 모바일에서는 가로 스크롤한다.

## 영상 재생 계약

1. 쿨터치 오버핏 반팔 셔츠
2. 메쉬 로우프로파일 스니커즈
3. 유틸리티 빅 토트백
4. 라이트 집업 재킷

- 섹션 진입 시 1번 영상부터 무음 자동 재생한다.
- 활성 영상이 끝나거나 로드하지 못하면 다음 영상으로 자동 전환한다.
- 4번 영상이 끝나면 반복하지 않고 정지한다.
- 섹션 이탈 뒤 재진입하면 모든 챕터를 초기화해 1번 영상부터 다시 재생한다.
- 음소거 해제·볼륨·재생 순서 변경 컨트롤은 제공하지 않는다.
- `prefers-reduced-motion: reduce`에서는 자동 재생하지 않고 포스터 이미지를 유지한다.

## 성능과 접근성

- 활성 챕터 하나만 `preload="metadata"`로 렌더링·재생한다.
- 각 영상의 포스터는 기존 Firebase Storage 메인 배너 이미지를 사용한다.
- 섹션 제목, 현재 챕터 수, 영상명, 4개 상품 링크에는 접근 가능한 텍스트 레이블을 제공한다.
