# 포트폴리오 데모 쇼케이스 안내 설계

## 목적

홈 최하단의 포트폴리오 안내를 일반 공지문 대신, 실제로 동작하는 커머스 포트폴리오의 구현 범위를 빠르게 파악할 수 있는 쇼케이스 구역으로 정리한다.

## 확정 방향

- 기존 홈 최하단 위치와 `PortfolioDemoSection` 컴포넌트를 유지한다.
- `PORTFOLIO DEMO`와 포트폴리오 구현 사실을 최우선 위계로 두고, 회원가입 포인트는 보조 정보로 낮춘다.
- 일반 쇼핑·주문 흐름, 관리자 운영 기능, 실제 결제 미진행 데모 고지를 카드가 아닌 세 개의 목록 행으로 분리한다.
- `구현 범위 자세히 보기` 버튼은 기존 `styna:open-site-guide` 동작과 접근성 의미를 그대로 유지한다.
- 기존 `--swatch-beige`를 섹션 전체 배경으로 사용해 스타일나우와 푸터 사이에 편집숍형 클로징 장면을 만든다.
- 왼쪽은 큰 포트폴리오 제목과 CTA, 오른쪽은 구현 범위 목록으로 구성한다. 새 그림자나 둥근 카드, 장식 효과는 추가하지 않는다.

## 화면과 반응형

- 데스크톱에서는 안내 제목과 구현 범위를 좌우 2열로 배치하며, 목록 행은 레이블과 설명을 나란히 표시한다.
- 모바일에서는 제목과 CTA 다음에 구현 범위 목록을 배치하고, 버튼은 전체 폭을 사용해 44px 이상의 조작 영역을 확보한다.
- 기존 데모 고지 문구와 정책 데이터의 사실 관계는 바꾸지 않는다.

## 범위와 검증

- 수정 대상은 `PortfolioDemoSection.tsx`, 해당 CSS 모듈, 관련 컴포넌트 테스트와 홈 정적 콘텐츠 검증이다.
- 상품, 주문, Firebase 데이터, 사이트 가이드의 동작과 다른 홈 섹션은 변경하지 않는다.
- 컴포넌트 테스트, 정적 콘텐츠 검증, 타입 검사·린트를 실행하고 데스크톱·모바일 화면에서 레이아웃과 버튼 동작을 확인한다.
