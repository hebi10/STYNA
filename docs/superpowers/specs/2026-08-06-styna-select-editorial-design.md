# STYNA SELECT 편집형 추천 상품 설계

## 목표

- 홈의 기존 추천 상품을 동일한 크기의 카드 매대가 아닌, 큰 무드 이미지와 세 개의 컴팩트 상품으로 구성된 편집형 `STYNA SELECT` 영역으로 바꾼다.
- 실제 독점 판매나 혜택이 없는 포트폴리오이므로 `EXCLUSIVE`라는 사실 주장 대신 관리자가 고른 큐레이션이라는 의미를 분명히 한다.

## 사용자와 성공 기준

- 방문자는 카테고리 다음 영역에서 한 가지 스타일 무드와 그에 맞는 상품 세 개를 빠르게 파악하고, 각 상품 상세 또는 전체 추천 목록으로 이동할 수 있어야 한다.
- 관리자는 기존 추천 상품 관리 화면에서 제목, 설명, 무드 이미지, 노출 순서를 설정할 수 있어야 한다.

## 선택한 방향

- 기존 `featuredProducts/mainPageFeatured` 문서와 상품 ID 순서를 그대로 사용한다.
- 데스크톱은 왼쪽 2/3 폭의 무드 이미지와 오른쪽 세 줄 상품 목록으로 구성한다. 모바일은 무드 이미지 다음에 상품 목록을 세로로 이어 붙인다.
- 섹션 제목은 기본값 `STYNA SELECT`, 보조 문구는 `지금 가장 잘 어울리는 세 가지 아이템을 골랐습니다`로 둔다. 관리자가 바꾸면 그 값을 표시한다.
- 기본 무드 이미지는 프로젝트의 기존 가을 스타일나우 이미지를 사용하고, 관리자가 유효한 내부 이미지 경로를 설정하면 이를 우선한다.

## 범위와 경계

- 수정 대상은 홈 추천 상품 컴포넌트, 추천 상품 Firestore 설정·관리 화면, 관련 테스트와 정적 콘텐츠 문서다.
- 신상품·베스트 랭킹·세일 상품의 데이터 기준과 UI는 변경하지 않는다.
- 신규 상품 데이터, 독점 혜택, 외부 링크 및 이미지 업로드 기능은 추가하지 않는다.

## 상태와 접근성

- 정상 상태는 최대 세 상품을 노출하며, 선택 상품이 1~2개여도 목록을 유지한다.
- 설정 조회 실패 시에는 공개 추천 상품 중 최대 세 개를 같은 편집형 레이아웃으로 보여 준다.
- 설정이 비활성화되었거나 유효한 상품이 없으면 기존처럼 섹션을 숨긴다. 로딩·오류·빈 상태의 재시도 흐름도 보존한다.
- 큰 이미지와 각 상품 링크에는 의미 있는 대체 텍스트와 키보드 포커스 표시를 제공한다.
