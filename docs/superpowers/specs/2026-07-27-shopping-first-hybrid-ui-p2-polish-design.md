# 쇼핑 우선 하이브리드 UI P2 폴리시 설계

## 목표

최종 Impeccable 비평에서 확인된 다섯 P2 문제를 제거해 모바일 조작 안정성, SHOP 탐색 구조, 콘텐츠 집중도, 접근성 대비와 페이지 heading, 빈 상태 복구 흐름을 한 단계 높인다.

## 승인된 방향

해비님이 2026-07-27 최종 비평에 제시된 다섯 수정안을 그대로 구현하도록 승인했다. 기존 쇼핑 우선 하이브리드 시각 세계와 로그인 동작은 보존한다.

## 설계

### 1. 모바일 상품 조작부

- 상품 상세의 사이즈, 색상, 수량 증감, 상세 탭, 문의하기 조작부는 모바일에서도 최소 `44×44px` hit area를 가진다.
- 색상 원형은 별도 장식 레이어를 만들지 않고 실제 버튼을 `44×44px`로 확대한다.
- 기존 선택, disabled, 장바구니, 바로구매, Q&A 이동 동작은 바꾸지 않는다.

### 2. SHOP 2단계 정보 구조

- SHOP 1차 목적지는 `전체 상품`, `카테고리`, `신상`, `베스트`, `세일`, `브랜드` 여섯 개로 고정한다.
- Firebase에서 불러오는 동적 카테고리는 `카테고리` 2차 disclosure 안에서만 노출한다.
- `/categories` 허브 진입은 `카테고리 전체 보기`로 보존한다.
- 데스크톱은 2차 Escape가 카테고리 disclosure만 닫고 카테고리 trigger로 포커스를 돌려준다. 부모 SHOP Escape 동작도 유지한다.
- 모바일 Escape는 기존처럼 전체 메뉴를 닫고 햄버거로 포커스를 돌려준다. 메뉴 닫힘·경로 이동·resize에서 하위 disclosure 상태를 초기화한다.

### 3. 메타데이터 정리

- 신상품 카드의 같은 의미를 가진 `NEW NEW` 이중 배지를 한 개로 줄인다.
- 전체 상품 목록 위의 현재 페이지/신상품/세일 통계 타일은 제거하고 기존 결과 안내를 유지한다.
- 홈의 반복 영문 eyebrow와 포트폴리오 연락처/데모 참고/service 정보 구역을 제거한다.
- 포트폴리오 설명은 기존 `PortfolioDemoSection` 한 구역과 공통 가이드에만 남긴다.

### 4. 대비, heading, 빈 상태

- `--text-soft`를 흰 배경에서 일반 텍스트 기준 `4.5:1` 이상인 값으로 교체하고 파생 muted/tertiary token도 함께 개선한다.
- `AsyncStatePanel`은 기본 `h2`를 유지하되 페이지의 유일한 제목일 때 `h1`을 선택할 수 있게 한다.
- 비로그인 장바구니와 인증 확인 상태는 페이지 수준 `h1`을 사용한다. FAQ는 하나의 `h1` 계약을 유지한다.
- `AsyncStatePanel`의 primary와 secondary action은 시각적으로 구분한다. primary는 검정 채움, secondary는 흰 표면과 검정 선을 사용한다.
- 이벤트가 0건이면 신상품과 전체 상품으로 이동할 수 있고, 필터 결과가 0건이면 전체 이벤트로 돌아갈 수 있다.

## 상태 및 오류

- Firebase 카테고리 조회 실패 시 SHOP 1차 링크와 카테고리 전체 보기는 계속 동작하며 빈 하위 목록은 렌더링하지 않는다.
- 이벤트 오류 상태와 재시도 동작은 이번 변경 범위 밖이며 기존 동작을 유지한다.
- demo login feature flag와 이메일/비밀번호 로그인, 일반/관리자 빠른 로그인 동작은 변경하지 않는다.

## 검증

- 모든 동작 변경은 실패하는 테스트를 먼저 확인한 뒤 최소 구현으로 통과시킨다.
- 집중 테스트 후 타입체크, ESLint warning 0, 전체 Jest, production build를 실행한다.
- `390×844`, `768×1024`, `1440×900`에서 상품 상세, SHOP, 홈, 상품 목록, 이벤트, 비로그인 장바구니, FAQ를 한 번의 배치로 확인한다.
- 마지막에 Impeccable 재평가를 수행하고 이전 `28/40` snapshot과 비교한다.

- 새 box-shadow 또는 border-radius 추가
