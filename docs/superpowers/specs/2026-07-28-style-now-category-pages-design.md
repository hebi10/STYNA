# 스타일나우 계절 카테고리·상세 화면 설계

## 확정 방향

- 홈의 스타일나우는 기존 탭과 상품 목록 대신 봄·여름·가을·겨울 이미지 카드 4개만 표시한다.
- 각 카드는 신규 생성한 4:3 계절 이미지를 사용하고 `/style-now/{season}`으로 이동한다.
- 계절 상세는 기존 9:27 화보의 첫 모델 장면과 신규 상품 강조 이미지 2장을 세로로 연결한다.
- 세 패널에는 이미지에 글자를 굽지 않고 실제 한국어 HTML 카피를 겹쳐 표시한다.
- 이미지 아래에는 기존 계절별 상품 20개와 `ProductCard` 상세 링크를 유지한다.

## 이미지 구성

- 신규 카테고리 이미지: 계절별 1장, 총 4장
- 신규 상품 강조 이미지: 계절별 2장, 총 8장
- 기존 모델 화보: 계절별 기존 9:27 이미지의 상단 장면을 크롭해 재사용
- 신규 자산은 기존 파일을 덮어쓰지 않는 `v2` 파일명으로 저장한다.

## 상호작용

- 홈 계절 카드는 전체가 링크이며 계절명과 한 줄 설명을 포함한다.
- 상세 라우트는 `spring`, `summer`, `autumn`, `winter`만 허용하고 나머지는 404로 처리한다.
- 상세 페이지에서 다른 계절로 바로 이동할 수 있는 계절 내비게이션을 제공한다.
- 상품 조회 로딩, 오류, 20개 미만 상태는 상세 콘텐츠 내부에서 처리한다.

## 레이아웃

- 홈 카드는 데스크톱 4열, 태블릿 2열, 모바일 1열로 배치한다.
- 상세의 세 편집 패널은 데스크톱에서 하나의 1:3 세로 비주얼처럼 보이게 연결한다.
- 첫 패널은 기존 모델 화보 상단을 정사각형으로 크롭한다.
- 두 번째와 세 번째 패널은 신규 정사각 상품 이미지다.
- 각 패널의 카피는 대비가 확보되는 단색 반투명 면 위에 배치한다.
- 상품은 기존 데스크톱 4열, 모바일 2열 규칙을 유지한다.
- 그림자와 라운드는 추가하지 않는다.

## 비목표

- 일반·관리자·개발용 로그인 변경
- 상품 데이터, Firebase 규칙, Storage 경로 변경
- 기존 상품 카드와 상품 상세 페이지 재설계
- 커밋, 푸시, 배포
