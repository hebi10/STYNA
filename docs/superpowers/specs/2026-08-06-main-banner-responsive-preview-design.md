# 메인 배너 데스크톱 정사각형·모바일 세로형 분리 설계

## 목표

- PC와 태블릿에서는 현재처럼 슬라이드당 정사각형 상품 배너 2개를 나란히 보여 주는 쇼핑형 구성을 유지한다.
- 모바일에서는 각 데스크톱 슬라이드 세트에 대응하는 새 세로형 이벤트 배너를 한 장씩 보여 주고, 배너 전체를 기존 이벤트 상세 페이지로 연결한다.
- 모든 환경에서 점 페이지네이션을 얇은 바 형태의 세그먼트 네비게이션으로 바꾼다.

## 범위와 비목표

- 대상은 `src/app/_components/MainBanner.tsx`, `MainBanner.module.css`, `MainBanner.test.tsx`, 새 모바일 이미지와 `docs/main-banner.md`다.
- PC·태블릿의 상품 카드 데이터, Firebase Storage 이미지 URL과 상품 상세 링크는 바꾸지 않는다.
- 기존 이벤트 상세 페이지·이벤트 데이터·새 라우트는 만들거나 수정하지 않는다.
- 드래그, 자동 재생, 무한 순환, 세션 복원, reduced motion 및 hover·focus 일시 정지는 유지한다.

## 콘텐츠 모델

- 데스크톱·태블릿은 현재의 5개 `bannerPair`와 각 쌍의 상품 카드 2개를 그대로 사용한다.
- 모바일은 같은 순서의 이벤트 캠페인 5개를 별도 슬라이드 데이터로 둔다. 5개라는 슬라이드 수를 유지해 하단 바 네비게이션의 길이와 조작 방식을 바꾸지 않는다.
- 모바일 세로형 이미지는 새로 제작해 `public/main/mobile-event-banner/`에 추가한다. 권장 비율은 3:4이며, 이미지 안에는 텍스트를 합성하지 않는다. 이벤트 제목과 설명은 접근 가능한 UI 텍스트로 표시한다.
- 모바일 이벤트 연결은 현재 제공 중인 아래 상세 경로를 사용한다.

  | 순서 | 이벤트 경로 | 이미지 주제 |
  | --- | --- | --- |
  | 1 | `/events/event-2026-08-summer-sale-edit` | 여름 끝자락의 가벼운 레이어링 |
  | 2 | `/events/event-2026-08-prefall-layering-new` | 프리폴 레이어링 |
  | 3 | `/events/event-2026-08-late-summer-style` | 늦여름 데일리 스타일 |
  | 4 | `/events/event-2026-08-bag-accessory-sale` | 데일리 백과 액세서리 |
  | 5 | `/events/event-2026-08-daily-bag-new` | 새 시즌 데일리 백 |

## 반응형 레이아웃

- 768px 이상에서는 기존의 정사각형 2카드 배너를 렌더링한다. 태블릿은 현재와 같은 활성 슬라이드 86%, 양옆 각 7% 프리뷰를 유지하고, 데스크톱은 70%(각 15%), 1600px 이상은 60%(각 20%)를 기준으로 한다.
- 767px 이하에서만 정사각형 상품 카드를 렌더링하지 않고, 세로형 이벤트 배너 하나를 화면 폭 전체에 표시한다. 양옆 프리뷰는 숨긴다.
- 두 뷰는 화면 크기에 따라 교체되지만 활성 슬라이드 번호는 공통으로 유지한다. 사용자가 태블릿과 모바일 경계를 오가도 현재 보던 순서를 잃지 않는다.
- 데스크톱·태블릿의 인접 슬라이드는 기존처럼 어둡게 처리하고 키보드 탭 순서에서 제외한다. 모바일에는 인접 프리뷰가 없으므로 활성 이벤트 배너만 탭 순서에 둔다.

## 하단 바 네비게이션

- 이미지 아래 별도 컨트롤 영역에 5개 동일 폭 세그먼트 바를 둔다. 현재 세그먼트만 검정색으로 채우고 나머지는 옅은 회색 선으로 표시한다.
- 이전·다음 버튼과 자동 재생 토글은 바 옆에 두며, 문자 화살표와 최소 44×44px 터치 영역을 유지한다.
- 세그먼트는 버튼으로 유지해 `aria-current`, `n번 배너 보기`, 전환 중 비활성화 정책을 보존한다. 자동 재생 경과를 별도 애니메이션으로 표시하지 않는다.

## 성능·접근성·검증

- 데스크톱·태블릿에서는 현재와 같이 최초 정사각형 이미지 한 장만 `priority`로 로드한다. 모바일에서는 최초 세로형 이벤트 이미지 한 장만 `priority`로 로드한다.
- 단위 테스트는 뷰포트별 콘텐츠 전환, 데스크톱의 기존 상품 링크, 모바일의 이벤트 링크 5개, 최초 단일 `priority`, 세그먼트 바 5개, 드래그 임계값, 전환 잠금, reduced motion을 검증한다.
- 브라우저에서 390px 모바일 세로형 슬라이드, 768px·1024px 태블릿 정사각형 2카드와 프리뷰, 1280px·1600px 데스크톱 프리뷰 비율을 확인한다. 모든 폭에서 바 컨트롤 줄바꿈, 링크 이동, 드래그와 클릭을 점검한다.
