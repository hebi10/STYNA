# 공개 관리자 데모 차단 설계

## 목적

공개 포트폴리오에서 일반 회원과 관리자 로그인 버튼을 유지하면서, 관리자 데모가 실제 운영 데이터·개인정보·변경 권한에 접근하지 못하게 한다. 실제 운영 관리자의 Firebase 권한과 내부 관리 화면은 유지한다.

## 범위

- `NEXT_PUBLIC_ENABLE_DEMO_LOGIN=true`일 때 일반 회원과 관리자 빠른 로그인 버튼을 모두 노출한다.
- 관리자 빠른 로그인은 별도의 읽기 전용 데모 주체로 인증하고, 실제 데이터 조회 없이 비민감 요약만 표시한다.
- 공개 사업자 정보에서 개인 전화번호를 제거하고 전화 상담 미제공으로 표시한다.
- 실제 Firebase Auth 비밀번호 변경, 토큰 폐기, Firestore 운영 데이터 정정과 배포는 포함하지 않는다. 이 작업은 별도 승인과 운영 절차가 필요하다.

## 결정

권한을 가진 계정이 실제 사용자·주문 데이터를 읽고 쓸 수 있는 현재 Rules와 Functions 구조에서는, 프런트엔드의 버튼 비활성화만으로 안전한 데모를 보장할 수 없다. 따라서 데모 주체는 실제 관리자 권한을 갖지 않고, 관리자 셸도 실제 관리 하위 화면을 마운트하지 않는다. Rules·Storage·Functions는 데모 주체의 관리자 읽기·쓰기를 모두 거부한다.

## 동작과 오류 처리

- 환경변수가 `true`인 경우: 일반 회원과 읽기 전용 관리자 빠른 로그인 버튼을 표시한다.
- 환경변수가 없거나 `false`인 경우: 빠른 로그인 영역을 표시하지 않는다.
- 일반 회원 빠른 로그인 실패 시 기존 로그인 오류 처리와 전환 상태를 그대로 사용한다.
- 지원 전화번호 위치에는 전화 상담을 제공하지 않는다는 고정 안내를 표시한다.

## 검증 기준

- 로그인 화면 테스트가 일반 회원과 관리자 버튼 존재를 검증한다.
- 관리자 데모 토큰은 실제 관리자 쓰기 권한을 획득하지 못한다.
- 사업자 안내가 개인 전화번호를 렌더링하지 않는다.
- 변경 범위 Jest, 타입 검사, lint를 실행한다.
