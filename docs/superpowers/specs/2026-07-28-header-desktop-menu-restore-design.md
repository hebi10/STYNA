# 데스크톱 헤더 메뉴 구성 복원 설계

## 목표

현재 헤더의 접근성, 반응형 처리, 모바일 disclosure 동작은 유지하면서 데스크톱 중앙 메뉴만 2026-07-27 개편 이전의 풍부한 직접 링크 구성으로 복원한다.

## 데스크톱 구성

- `960px` 이상에서는 `전체 상품`, `신상`, `베스트`, 활성 카테고리 중 첫 번째 항목, `세일`, `브랜드`를 직접 노출한다.
- `1280px` 이상에서는 구분선 뒤에 `추천`, `이벤트`, `리뷰`, `1:1문의`, `상품문의`를 추가로 직접 노출한다.
- 활성 카테고리를 불러오지 못한 경우 대표 카테고리 자리에는 `/categories`로 이동하는 `카테고리` 링크를 표시한다.
- 검색, 장바구니, 로그인·마이페이지, 관리자 메뉴는 현재 위치와 동작을 유지한다.

## 유지할 현재 개선

- 모바일은 현재의 `SHOP`, `추천`, `이벤트`, `리뷰`, `고객지원` 그룹과 중첩 disclosure 구조를 그대로 사용한다.
- 모바일 dialog, 스크롤 잠금, focus trap, Escape 처리, viewport 전환 상태 초기화를 유지한다.
- 헤더 내부 이동이나 pathname 변경 시 열린 메뉴를 닫는 현재 처리를 유지한다.
- 현재 로고, 공지 영역, 사용자 메뉴 스타일은 변경하지 않는다.

## 구현 범위

- 공유 내비게이션 데이터에서 데스크톱 직접 링크 목록과 모바일 그룹 목록을 각각 제공한다.
- `Header`는 viewport별 기존 CSS 노출 규칙을 활용해 데스크톱 기본 메뉴와 보조 메뉴를 렌더링한다.
- 예전 `Header` 파일 전체를 되돌리지 않고 필요한 메뉴 구성과 스타일만 현재 코드에 맞게 복원한다.

## 검증

- 내비게이션 데이터 테스트에서 데스크톱 기본·보조 메뉴의 순서와 링크를 확인한다.
- 헤더 테스트에서 데스크톱 직접 링크와 현재 모바일 disclosure 동작이 함께 유지되는지 확인한다.
- 타입 검사와 관련 테스트를 실행한다.
- 가능하면 브라우저에서 `960px`, `1280px` 전후 레이아웃과 링크 동작을 확인한다.
